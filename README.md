# Sauna Station Mock

サウナ施設の予約・管理システムのモックアプリケーションです。一般ユーザー、施設運営者、システム管理者の 3 つのユーザータイプに対応した包括的なプラットフォームです。

## 🏗️ アーキテクチャ

### 技術スタック

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Icons**: Heroicons
- **Font**: Inter (Google Fonts)

### ディレクトリ構造

```
src/
├── auth/
│   └── AuthApp.js              # 認証コンポーネント（ログイン・登録）
├── components/
│   ├── Header.js               # 共通ヘッダーコンポーネント
│   ├── Layouts.js              # Manager/Admin用レイアウト
│   └── BookingModal.js         # 予約確認モーダル
├── pages/
│   ├── UserPages.js            # 一般ユーザー向けページ
│   ├── ManagerPages.js         # 施設運営者向けページ
│   ├── AdminPages.js           # システム管理者向けページ
│   └── OnboardingPage.js       # 施設運営者オンボーディング
├── App.js                      # メインアプリケーション
└── index.css                   # グローバルスタイル
```

## 🚀 機能一覧

### 一般ユーザー向け機能

- **トップページ**: ヒーローセクション、人気施設表示
- **施設検索**: 場所、キーワード、価格帯での検索・フィルタリング
- **施設詳細**: 施設情報、設備・サービス、営業時間、アクセス情報
- **予約システム**: 週単位カレンダー、混雑度表示、予約確認モーダル
- **マイページ**: ユーザー情報、予約履歴管理
- **認証**: ユーザー登録・ログイン機能

### 施設運営者向け機能

- **オンボーディング**: 5 ステップの施設登録プロセス
- **ダッシュボード**: 本日の予約、売上速報
- **予約管理**: カレンダー形式での予約一覧・管理
- **予約枠管理**: 予約枠の追加・削除、CSV 一括登録
- **営業時間管理**: 曜日別営業時間設定
- **施設情報編集**: 基本情報の更新
- **スタッフ管理**: 将来的な拡張機能

### システム管理者向け機能

- **企業・施設管理**: 登録施設の一覧・管理
- **担当者アカウント管理**: 施設担当者アカウントの管理

## 📱 使用方法

### 一般ユーザー

1. トップページで施設を検索
2. 施設詳細ページで予約可能時間を確認
3. 希望の時間枠を選択して予約
4. マイページで予約履歴を管理

### 施設運営者

1. トップページの「施設運営者の方はこちら」からオンボーディング開始
2. 5 ステップの登録プロセスを完了
3. ダッシュボードで予約・売上を管理
4. 各種管理機能で施設運営

### システム管理者

1. 管理者ログインでシステムにアクセス
2. 企業・施設の管理
3. 担当者アカウントの管理
